# Exercício 1 — GitHub e Controlo de Versões

## Objetivo

Criar e organizar um repositório no GitHub, utilizando ficheiros, pastas e commits.

## Tarefas Realizadas

1. Criação do repositório `java-web-aluno`.
2. Configuração da visibilidade como privada.
3. Criação e preenchimento do ficheiro `README.md`.
4. Criação da pasta `documentacao`.
5. Criação do ficheiro `descricao-exercicio1.md`.
6. Registo das alterações no histórico de commits.

## Conclusão

Este exercício permitiu compreender a importância do GitHub na organização de projetos, na documentação e no controlo de versões. Os commits permitem acompanhar as alterações realizadas ao longo do desenvolvimento.
